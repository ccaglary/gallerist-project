# Gallerist Project

Bu proje, Java Spring tabanlı bir galeri yönetim sistemidir. 

## Özellikler
- Kullanıcı ve yetkilendirme yönetimi
- Araç ekleme, silme, güncelleme
- Satış ve müşteri yönetimi
- JWT tabanlı güvenlik

## Kurulum
1. Java 17+ ve Maven yüklü olmalı.
2. `mvnw clean install` ile projeyi derleyin.
3. `mvnw spring-boot:run` ile başlatın.
